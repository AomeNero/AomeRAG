# 电测产品履历查询

## 目的与数据

本 skill 基于内置的 `references/电测产品履历表.md`（即"电测产品履历表"），回答公司电测产品线的各类查询。该履历表是所有回答的**唯一数据来源**；不要凭记忆或猜测回答任何型号、版本、规格、状态或客户信息。

履历表按产品系列组织，共 29 个系列（GS321I、GS031I、GS033、EP320/EP321/EP322、EP325、EP326、GI361、GI351、GI350、GS360、GS360U、GS370、GI150&GI150P、GI329、GI327&GS327N、GI328&GI328N、CG512C&CG512T、CG602C&CG602T、SG500、SG048、CG513、CG513M-P/T/E、CG515、CG603、CG605、PG600A1、MPG3801、MCG100、加电系统）。每个系列下列出物料行，每行含：

- **物料编码**：如 `2030100023`（编号第 2 段 "010" 前缀常见为讯号发生器，"016" 为衍生/替代版本，"020/030/040" 多为历史或特殊系列，不必靠编号判断类别）
- **物料名称**：产品型号 + 版本/外壳/接口描述，如"GS321I-A（16laneVX1/LVDS/EDP版）(黑色细砂纹，钣金)"
- **规格**：版本编号（版本A/B/C…）及该版本的信号支持、电源输出、变更说明；常以"在版本X基础上…"描述演化
- **当前状态**：推广 / 停产 / 定制 / 已完成测试 / 待停用 / 设计中 等，可能两个并存（如"推广/已完成测试"）
- **出货客户**：如 B4、惠科、苏州三星、天马、合肥高创 等；空表示未标注特定客户

配套件常分成子表：主机、转板套件、扩展盒、支架套件、包材套件、电源转板套件 等。

## 查询流程

1. **识别系列与需求**：从提问中提取产品系列/型号（如 GS321I、GI361M-P），判断属于哪类查询（见回答模板）。
2. **定位数据**：先用 Grep 在 `references/电测产品履历表.md` 中定位系列标题（如 `## GS321I`），再 Read 读取该系列整段（从该 `##` 到下一个 `##`）。不要一次性读取整个文件，节省上下文。若用户只给了一个模糊型号，可先 Grep 该关键词确认系列归属。
3. **提取并回答**：从对应表格行提取信息，按模板组织答案。查不到时明确说明"履历表中未收录该型号/信息"。

## 回答模板

### 1. 型号规格查询

用户问某型号"支持什么信号 / 电源规格 / 是做什么的"时：

- 列出该型号的所有版本（版本A、B、C…），每个版本一句话说明其信号支持与电源规格
- 对"在版本X基础上…"的版本，说明相对上一版/基础版的**变更点**（增加/去掉哪些信号板卡、更换物料、结构或三防变化、替代料等）
- 标注每个版本对应的物料编码与当前状态
- 存在"内部板卡配置相同、仅丝印/名称不同"的衍生型号（如 GS322I-A 之于 GS321I-A）时，一并列出并说明"仅名称/丝印不同"

### 2. 按种类列型号

用户问"有哪些检测机 / 讯号发生器 / cell产品 / 电源盒…"时：

- 先识别产品种类。常见对应关系（同一型号可横跨多个种类）：
  - **讯号发生器/信号发生器**：GS321I、GS031I、GS033（主PG）、GI361、GI350、GI329、GI327、GI328、MPG3801、SG500（探针短接式图形信号发生器）
  - **检测机/检查机**：GI351（单点位信号检查机）、GS370（单点位信号检查机）、GI150/GI150P、CG512、CG513、CG513M、CG515、MCG100
  - **cell 产品/cell测试**：CG513M-P/T/E、CG515（CELL Test PG）、CG603M、MCG100
  - **Aging/老化设备**：GS360、GS360U、GS370、CG602、CG603、CG605
  - **程控电源盒/背光电源**：EP320/EP321/EP322、EP325、EP326、EP329、GI329 程控电源盒
  - **ShortingBar 设备**：CG512、CG602、CG513、CG603、PG600A1
  - **加电系统**：UDS100、PDS201、AJS101
  - **电流检测盒**：SG048
- 列出该种类下所有型号 + 物料编码 + 一句话定位（是做什么的）
- 注意区分"主机/整机"与"套件"：用户问型号时默认指整机，除非用户提到套件

### 3. 状态与客户查询

- 给出型号（或物料编码）的当前状态（推广/停产/定制/已完成测试/待停用/设计中）
- 给出出货客户；无客户标注时说明"未标注特定出货客户"
- 若状态栏有替代提示（如"停产/使用2030160022主机"），一并提示用户可用的替代型号/物料编码

### 4. 版本演进 / 对比

- 按版本字母顺序（版本A→B→C…）整理演进路径，说明每次版本的变更点
- 注意区分两件事：**版本升级**（规格/板卡变化，同系列内如"在版本A基础上增加…"）与**衍生型号**（仅丝印/名称/外壳材质不同）
- 对比两个型号时，逐项列出：基础版本、信号支持、电源输出、外壳材质/颜色、当前状态、出货客户 的异同

## 注意事项

- **以履历表为准**：履历表是唯一事实来源。规格栏中"具体规格描述请参考产品规格书"表示履历表不含全部细节——如实转述即可，不要自行补充或编造细节。
- **版本 ≠ 物料**：同一"产品"名下多个物料编码可能对应不同版本或仅丝印不同的衍生型号。回答时区分"版本变化"与"衍生型号"。
- **状态双值**：部分型号状态栏同时写两个状态（如"推广/已完成测试""未完成测试/停用"），如实全部列出。
- **不要合并**：不要把不同系列、不同版本的规格混在一起回答；找不到就明确说不收录，不要推测。
